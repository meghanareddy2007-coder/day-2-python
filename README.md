This project is a Smart ID & Credential Validator for a university registration system as part of the Python Code2Xplore – 60 Days Challenge (DAY-2). The program takes Student ID, Email ID, Password, and Referral Code as input and verifies them based on strict university rules using only strings and conditional statements. Student IDs must follow the format CSE-XXX, emails must contain @ and .edu, passwords must be at least 8 characters long with an uppercase first letter and at least one digit, and referral codes must follow the format REF##@. If all credentials are valid, the system prints APPROVED, otherwise it prints REJECTED. This challenge avoids loops, lists, dictionaries, regex, and advanced libraries, focusing on basic string manipulation and condition checking.
